# YT Folder Icon (C# / WPF)

نسخة C# من تطبيق "ثمنيل يوتيوب → أيقونة فولدر".

## المتطلبات
- Windows 10/11
- .NET 8 SDK  (للبناء)  أو .NET 8 Desktop Runtime (للتشغيل فقط)

## التشغيل
    dotnet run

## بناء EXE
    build_exe.bat

## الملفات
| الملف | الدور (يقابل في بايثون) |
|---|---|
| MainWindow.xaml / .xaml.cs | الواجهة (yt_folder_icon_ui.py) |
| YtCore.cs | المنطق: تحميل/قص/ICO/desktop.ini/البلاي لست (yt_core.py) |
| Lang.cs | اللغات الخمس (yt_lang.py) |
| Themes.cs + App.xaml | الثيمات وأنماط العناصر (بديل ttkbootstrap) |

## ملاحظات
- خيار **Shorts**: يحمّل ثمنيل الشورتس طولي 9:16 (يشيل الحواف السودا الجانبية) ويعمل أيقونة طولية في نص المربع. الخيار يطبّق على كل الروابط في نفس التشغيل.
- ملف الإعدادات هو نفسه `~/.yt_folder_icon.json` فإعدادات نسخة بايثون تعمل هنا.
- البلاي لست الكاملة: ضع `yt-dlp.exe` بجانب البرنامج (أو في PATH) لأفضل نتيجة،
  وإلا تُستخدم الطريقة المدمجة تلقائياً.
- معالجة الصور تستخدم System.Drawing (لا حاجة لأي حزمة NuGet).
